--- p3 ---
validación cruzada: el problema
Formulario con "contraseña" y "confirmar contraseña"
con un validator aislado por campo, 
¿cómo saben que ambos coinciden?
El validator de un campo no recibe por sí solo el valor del otro campo

--- p4 ---
validación cruzada: la solución
Leer el .text del otro 
TextEditingController al momento de 
validate()
O elevar el estado a un ChangeNotifier 
compartido entre ambos campos
Mismo patrón aplica a coherencia entre fechas, rangos mínimo-máximo

--- p7 ---
el paquete http
01
http.get(Uri.parse(url)) envía 
una solicitud GET
02
La respuesta trae un código 
de estado (200, 404, 
500...) y un cuerpo en JSON
03
jsonDecode(response.body) 
convierte el texto JSON en 
un Map o List de Dart

--- p8 ---
de json a objeto dart
fromJson(Map<String, dynamic> json) 
construye un objeto Dart desde el Map 
decodificado
toJson() hace el camino inverso, útil para 
enviar datos (POST/PUT)
Separar esta lógica del widget mantiene la pantalla enfocada en la interfaz

ng → mientras la
